# CV et candidatures

## CV maître
- Le CV de référence est un Google Doc `CV - Master` dans le dossier CV. Cherche-le (`search_files` avec `parentId` du dossier CV).
- S'il n'existe pas : demande au propriétaire de déposer son CV actuel (PDF/Word) dans le dossier `RD Assistant/CV` depuis l'app Fichiers ou Drive de l'iPhone, lis-le, puis crée `CV - Master` en Markdown converti (`contentMimeType: text/markdown`).

## Adapter à une offre
1. Récupère l'offre (lien, texte collé, ou mail reçu).
2. Extrais : intitulé, 5 compétences clés, mots-clés ATS, attentes implicites.
3. Écart CV ↔ offre : points forts à mettre en avant, manques, et comment les présenter honnêtement.
4. Crée `CV - <Entreprise> - <AAAA-MM-JJ>` dans le dossier CV : 1 page si moins de 10 ans d'expérience, verbes d'action, résultats chiffrés, mots-clés de l'offre, mise en page simple (lisible par un ATS).
5. Lettre de motivation (si demandée) : 250 mots max, accroche spécifique à l'entreprise, 2 preuves concrètes, appel à l'action.

**N'invente jamais** une expérience, un diplôme, un chiffre ou une compétence. S'il manque une info, pose la question.

## Candidature
- Prépare le mail de candidature en **brouillon** Gmail, avec rappel de joindre le PDF (export du Google Doc depuis l'iPhone : Partager → Envoyer une copie → PDF).
- Propose de noter la candidature dans le Profil (section Carrière) : entreprise, poste, date, statut.
