Avec Siri, même téléphone verrouillé

Dis : « Dis Siri, envoie un message audio à lui », puis parle. Il reçoit ta voix telle quelle, dans la langue que tu veux, et son iPhone la joue tout de suite.

Une fois, si Siri te demande de déverrouiller (noms des menus devinés) : Réglages, Siri, active « Autoriser Siri en mode verrouillé » ; puis Réglages, Face ID et code, « Autoriser l’accès en mode verrouillé » : active Siri.

Ouvre le lien d’invitation que tu as reçu : il contient ta clé. Sans lui, cette page ne peut rien envoyer.

Message vocal

Depuis cette page. Il l’entend avec ta voix, telle quelle ; une notification part, puis un rappel toutes les 5 minutes jusqu’à ce que ce soit fait.

Tes tâches envoyées

    Rien d’envoyé pour l’instant.

    Par JARVIS, avec un raccourci (téléphone déverrouillé)

    Une fois, dans l’app Raccourcis (noms des menus devinés, ils peuvent varier un peu) :

    1. Touche « + », puis nomme le raccourci « Message pour lui ».
    2. Ajoute « Enregistrer de l’audio » ; touche la flèche : « Commencer l’enregistrement » = Immédiatement (tu touches l’écran pour arrêter).
    3. Ajoute « Obtenir le contenu de l’URL », avec l’adresse
    4. Touche la flèche de cette action : méthode POST ; en-tête Authorization = Bearer … ; corps de la requête Fichier = « Audio enregistré ».
    5. Ajoute « Énoncer le texte » avec « Contenu de l’URL » : Siri te dira « Message vocal envoyé ».
    6. Ajoute « Envoyer un message » : à lui, message = « 🔔 » seulement ; touche la flèche et désactive « Afficher lors de l’exécution ». C’est la sonnette : son iPhone joue ta voix, telle quelle.
    7. Essaie : « Dis Siri, message pour lui », parle, puis touche l’écran (Siri demande de déverrouiller : c’est pour ça que le message audio de Messages, plus haut, passe en premier).
