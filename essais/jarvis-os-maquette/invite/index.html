    Rien d’envoyé pour l’instant.

    Avec Siri : « Dis Siri, tâche pour lui »

    Une fois, dans l’app Raccourcis de ton iPhone (noms des menus devinés, ils peuvent varier un peu) :

    1. Touche « + », puis nomme le raccourci « Tâche pour lui » : c’est la phrase à dire à Siri.
    2. Ajoute l’action « Dicter le texte » (langue : français).
    3. Ajoute « Obtenir le contenu de l’URL », avec l’adresse
    4. Touche la flèche de cette action : méthode POST ; en-tête Authorization = Bearer … ; corps de la requête JSON : un champ texte « texte » = « Texte dicté ».
    5. Ajoute « Énoncer le texte » avec « Contenu de l’URL » : Siri te dira « C’est noté ».
    6. Essaie : « Dis Siri, tâche pour lui », puis dicte la tâche (« … pour demain » met la date).
