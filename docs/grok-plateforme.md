# Ce que la plateforme Grok Bot permet (relevés de docs.x.ai)

Texte déplacé de CLAUDE.md le 13/11/2026. La plateforme change vite : revérifie dans la doc avant de t'appuyer sur un point.

Ce que la plateforme permet (vérifié le 10/11/2026 dans docs.x.ai) : un ordinateur et un dossier `/workspace` partagés par tous les bots ; mémoire séparée par bot ; skills privés communs ; routines déclenchées par horaire, par webhook ou par un mail reçu sur l'adresse des bots (pas par un événement Gmail ou Agenda) ; applications connectées valables pour tous les bots (un bot peut donc lire tout Gmail et tout Drive) ; une règle « Ask first » l'emporte toujours, même après « Always allow », et une demande d'accord née d'une routine expire après 30 minutes sans que l'action soit faite ; le contrôle voit l'identifiant d'un fichier, pas son nom : n'écris pas de règle qui dépend d'un nom de fichier ; un mail parti d'une routine attend en brouillon ; limiter les sites joignables est réservé aux comptes Enterprise ; supprimer un bot efface ses conversations, sa mémoire et ses routines, pas les fichiers de l'ordinateur partagé. Vérifié le 11/11/2026 : depuis l'iPhone, « Partager » envoie une photo, un fichier ou un lien à un bot ; l'app ajoute à Raccourcis et à Siri l'action « Send Message » ; un bot peut lire et écrire le Calendrier et les Rappels du téléphone, mais seulement dans un chat et app ouverte, jamais dans une routine ; les notifications sur iPhone sont encore en cours de déploiement ; un webhook est un POST avec un en-tête `Authorization: Bearer`, dont le corps JSON est transmis au bot ; au plus 300 passages de routine par heure ; le bot principal (Iris) relance de lui-même. Vérifié le 12/11/2026 (docs.x.ai et blog Tailscale du 09/11/2026) : un bot ne lance une commande sur l'ordinateur personnel du propriétaire que si cette capacité est activée et qu'il l'approuve, commande par commande (« Ask every time » par défaut) ; le plugin Tailscale de l'app de bureau fait entrer Grok Bot dans le réseau privé comme un appareil, pour joindre des serveurs MCP privés ; « Route traffic through this computer » change seulement l'adresse IP vue par les sites, sans ouvrir le réseau local ; Team Setup Scripts et Network Controls sont réservés à Enterprise ; la page des applications connectées ne cite ni Dropbox ni OneDrive (Dropbox n'existe que par des intermédiaires comme Composio). Agenda Google (constaté le 12/11/2026) : un événement de type BIRTHDAY revient chaque année tout seul et refuse récurrence, visibilité et disponibilité ; un rappel en minutes négatives est accepté (-540 = le jour même à 9h). Revérifie dans la doc avant de t'appuyer dessus : la plateforme change vite.

13/11/2026 (docs.x.ai, FAQ Grok Bot, Grok Bot dans l'abonnement X, limites d'usage) : l'usage est une réserve hebdomadaire partagée avec les apps Grok et Cursor, comptée en étapes d'agent et en tokens ; ni sa taille ni le coût d'un passage de routine ne sont publiés ; consommation visible sur grok.com/dashboard, rubrique Usage (ou Settings, Usage & Billing) ; un plafond n'arrête pas une tâche en cours. Mesure d'Iris du 3 au 10/11/2026 : chats 22 % de toute la consommation, routines d'Iris 4 %, messages entre bots 3 %.
